PORTFOLIO — FATOU POUYE THIAW

FICHIERS
- index.html : structure et contenu du site
- style.css : couleurs, typographie, mise en page responsive
- script.js : menu mobile et année automatique
- assets/ : ajoute ici ta photo et tes images de projets

OUVRIR LE SITE
1. Décompresse le dossier si nécessaire.
2. Ouvre index.html dans un navigateur (Chrome, Firefox, Edge).
3. Pour modifier le code, utilise Visual Studio Code.

PERSONNALISATIONS IMPORTANTES AVANT PUBLICATION
1. PHOTO : place ton portrait dans assets/ma-photo.jpg. Dans index.html, remplace le bloc <div class="photo-placeholder">...</div> à l'intérieur de .photo-frame par :
   <img src="assets/ma-photo.jpg" alt="Portrait de Fatou Pouye Thiaw">
2. EMAIL : remplace ton.email@example.com par ton adresse email dans le lien mailto et le texte affiché.
3. RÉSEAUX : remplace les liens LinkedIn et GitHub par tes vrais profils. Si tu n'en as pas, retire ces liens.
4. PROJETS : les cartes actuelles sont des exemples de présentation. Remplace-les par tes vrais projets, captures d'écran et affiches Canva. Ne présente pas les modèles comme des réalisations déjà faites.
5. BOUTIQUE : ajoute le nom de ta boutique, ses photos et le lien vers ses réseaux si tu souhaites la promouvoir.

Le site est statique et n'envoie pas de formulaire de contact à un serveur. Le lien e-mail ouvre le logiciel de messagerie de la personne qui clique.

Le site charge les polices DM Sans et Playfair Display depuis Google Fonts ; si la connexion est indisponible, des polices de remplacement sont prévues.
